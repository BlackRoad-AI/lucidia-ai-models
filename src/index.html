classes & dataclasses
AIModelRegistry class · core Universal AI model memory hub. Manages model registration, version tracking, benchmarking, and metrics aggregation. Persists all data in a local SQLite database at ~/.blackroad/ai_models.db.
register_model get_model list_models add_version get_versions benchmark_model get_metrics close
ModelEntry dataclass · model Represents a registered AI model. Fields: model_id (auto UUID8), name, provider, architecture, parameter_count, license (apache-2.0), tags, created_at.
huggingface meta openai anthropic deepseek alibaba blackroad
ModelVersion dataclass · versioning Tracks model checkpoints. Fields: version_id, model_id, version (semver), checkpoint_path, training_steps, is_latest, notes, created_at.
BenchmarkResult dataclass · benchmarking Records evaluation results. Fields: bench_id, model_id, version_id, task (mmlu/hellaswag/humaneval), score, latency_p50_ms, latency_p99_ms, throughput_rps, gpu_memory_gb, notes, created_at.
mmlu hellaswag humaneval latency throughput
ModelMetrics dataclass · aggregation Aggregate metrics per model: total_versions, total_benchmarks, best_score, avg_latency_ms, last_updated.
cli commands
register cli · subcommand Register a new AI model. Args: --name, --provider, --arch, --params, --tags.
list cli · subcommand List all registered models. Optional: --provider filter.
version cli · subcommand Add a version checkpoint. Args: --model-id, --version, --steps, --path, --notes.
benchmark cli · subcommand Record a benchmark result. Args: --model-id, --task, --score, --p50, --p99, --tps.
metrics cli · subcommand Show aggregate metrics for a model. Args: --model-id.
get cli · subcommand Get full details for a specific model. Args: model_id (positional).
